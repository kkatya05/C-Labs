# Лабораторная работа № 2

Структуры данных и динамическое программирование.

## Цель

Найти кратчайший замкнутый маршрут по заданным точкам с помощью динамического программирования и подобрать экономное представление данных.

## Постановка задачи

Вводятся n точек с координатами X и Y. Нужно начать в первой введенной точке, посетить каждую из остальных ровно один раз и вернуться в первую. Расстояние между точками — длина прямого отрезка:

`d(i, j) = sqrt((xi - xj)^2 + (yi - yj)^2)`.

Переход разрешен между любыми двумя точками. Это евклидова задача коммивояжера. Программа принимает от 1 до 18 точек, координаты по модулю не больше 1000000. Ограничения позволяют контролировать расход памяти и численные значения. Совпадающие координаты допустимы: точки различаются номерами. Выводятся номера точек маршрута и его длина с тремя знаками после запятой. При нескольких оптимальных маршрутах выводится один из них.

## Структуры данных

Координаты хранятся в vector из простых структур Point, содержащих два числа double. Расстояния хранятся в одномерном массиве dist: элемент i * n + j соответствует переходу из i в j. Это позволяет не вычислять квадратные корни при каждом переходе динамики.

Посещенные точки представлены целым числом mask — битовой маской. Каждая позиция в двоичной записи отвечает за одну точку. Первая точка в маску не входит, поскольку старт всегда фиксирован. Например, для трех остальных точек маска 5 имеет вид 101: посещены точки 2 и 4.

В коде `1 << j` задает бит j, `mask & (1 << j)` проверяет его наличие, а `mask ^ (1 << j)` удаляет заведомо установленный бит.

Пусть m = n − 1. Таблица dp содержит m * 2^m чисел double и хранится в одном непрерывном vector. Элемент `dp[mask * m + j]` — минимальная длина пути из первой точки в точку j + 2, посещающего ровно множество mask. Состояния, где конечная точка не входит в mask, не используются.

Отдельная таблица предков не нужна: маршрут восстанавливается повторным выбором минимума из уже вычисленных значений dp. Также не хранятся все возможные маршруты. Исключение стартовой точки из маски сокращает таблицу по сравнению с n * 2^n состояниями.

Это компромисс между простотой, скоростью и памятью. Абсолютный минимум памяти не заявляется: можно уплотнить допустимые состояния или хранить только слои по размеру подмножества, но индексация и восстановление пути станут сложнее. Симметричную матрицу расстояний также можно сжать либо вычислять расстояния заново; здесь она мала по сравнению с dp.

## Динамическое программирование

Начальные состояния: для каждой точки j записываем расстояние от старта до нее:

`dp[{j}, j] = d(0, j)`.

Здесь в математической записи j обозначает точку, отличную от стартовой 0. Для множества S, содержащего j, переход имеет вид:

`dp[S, j] = min(dp[S без j, k] + d(k, j))`,

где k перебирает точки множества S без j. Недостижимые состояния первоначально равны большому числу INF.

Маски перебираются по возрастанию. Удаление установленного бита уменьшает маску, поэтому нужные предыдущие состояния уже вычислены.

После посещения всех точек нужно добавить возвращение в старт:

`ответ = min(dp[все точки, j] + d(j, 0))`.

Запоминаем конечную точку, давшую минимум. Далее движемся назад: исключаем ее из маски и выбираем предыдущую точку по той же формуле. Полученные номера записываем в маршрут справа налево. Первая и последняя позиции маршрута содержат старт.

При n = 1 маршрут равен 1 → 1, длина равна нулю.

## Обоснование правильности

Для пути через одну промежуточную точку ответ равен расстоянию до нее. Рассмотрим оптимальный путь через S с концом j. Перед j обязательно стоит некоторая точка k из S без j. Часть пути до k должна быть кратчайшей для своего состояния: иначе ее можно заменить более короткой и улучшить весь путь. Формула перебирает все допустимые k и выбирает минимум, поэтому по индукции таблица содержит оптимальные длины для всех состояний.

Каждый переход добавляет одну еще не посещенную точку, поэтому повторных посещений нет. В финале перебираются все возможные последние точки и добавляется ребро в старт. Следовательно, выбирается кратчайший замкнутый маршрут. Расчеты выполняются в double и могут иметь небольшую погрешность округления.

## Вычислительные и емкостные затраты

Предварительный расчет расстояний занимает O(n²) времени и памяти. Таблица имеет m * 2^m ячеек. Для каждого состояния перебирается до m предшественников, поэтому время динамики составляет O(m² * 2^m), или O(n² * 2^n). Это существенно лучше полного перебора (n − 1)! порядков посещения, но все еще экспоненциально.

Для m ≥ 2 число рассмотренных допустимых переходов составляет m * (m − 1) * 2^(m − 2): выбираются конечная и предыдущая точки, а остальные биты могут быть любыми. Проверки циклов не меняют асимптотику. Восстановление занимает O(n²) времени и O(n) памяти для маршрута.

Основная память: O(m * 2^m + n²), то есть O(n * 2^n). При double размером 8 байт таблица занимает `8 * m * 2^m` байт. Для n = 18 это 17825792 байта, или 17 МиБ. Матрица расстояний занимает 2592 байта, координаты — около 288 байт, маршрут при четырехбайтовом int — 76 байт. Служебные данные vector и отдельные переменные в этот расчет не включены.

## Пример

Вход:

```text
4
0 0
1 0
1 1
0 1
```

Кратчайший маршрут проходит по сторонам квадрата, например 1 → 4 → 3 → 2 → 1. Длина равна 4.000. Обратное направление имеет ту же длину.

## Вывод

Реализован точный алгоритм динамического программирования для задачи коммивояжера. Битовая маска компактно описывает множество посещенных точек, а таблица сохраняет результаты подзадач. Восстановление по таблице позволяет не хранить предков. Из-за экспоненциального роста затрат решение предназначено для небольшого количества точек.

# Лабораторная работа № 1. Алгоритмы сортировки

- `task1.cpp` — сортировка подсчетом: баллы от 0 до 100.
- `task2.cpp` — сортировка вставками: небольшой список целых чисел.
- `doc/report.md` — отчет с постановками задач, обоснованиями и расчетами сложности.

Каждый файл запускается отдельно, у каждого свой `main`.
Команды для PowerShell из папки `lab1`:

```powershell
g++ task1.cpp -o task1.exe
.\task1.exe

g++ task2.cpp -o task2.exe
.\task2.exe
```

Сначала введите количество чисел, затем сами числа через пробел или перевод строки.
Обе программы сортируют по возрастанию. Подсказки в консоли на английском,
как в примерах из `parallel/hw`, чтобы не зависеть от кодировки терминала.

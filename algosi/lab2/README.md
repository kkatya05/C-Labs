# Лабораторная работа № 2

`main.cpp` — кратчайший маршрут через все точки с возвращением в первую.
`doc/report.md` — постановка задачи, структуры данных, алгоритм и оценки затрат.

Запуск из папки lab2 в PowerShell:

```powershell
g++ main.cpp -o main.exe -std=c++11
.\main.exe
```

Введите количество точек (1–18), затем для каждой X и Y через пробел.
Координаты могут быть дробными (через точку), их модуль не должен превышать 1000000.
Номера точек в результате начинаются с 1. При большом числе точек расчет может занять время.
